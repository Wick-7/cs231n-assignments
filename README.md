# CS231n Assignments

My solutions to the Stanford CS231n programming assignments.

- Course: [CS231n: Deep Learning for Computer Vision](https://cs231n.stanford.edu/assignments.html)
- Assignments: 1–3

The repository contains assignment notebooks and supporting code. Downloaded datasets,
compiled files, and generated model artifacts are excluded; use the download scripts
included with each assignment to retrieve the data needed to run the notebooks.

Course-provided starter materials remain the property of their respective authors.
Please follow the course Honor Code when using this repository.
